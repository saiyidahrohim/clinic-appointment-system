# User Stories

## User Stories – Clinic Appointment System

1. As a patient, I want to book a clinic appointment, so that I can consult a doctor at my preferred date and time. (FR1)

Acceptance criteria:

- I cannot book an appointment until I fill in my name, contact number, appointment date, and preferred time.
- I can select an available doctor and appointment slot.
- The system must prevent me from booking a time slot that is already fully booked.

2. As a patient, I want to view my appointment details, so that I can check my appointment schedule and avoid missing my consultation. (FR2)

Acceptance criteria:

- I can view my appointment date, time, doctor’s name, and appointment status.
- I can only view appointments associated with my registered account.
- I can see whether my appointment is pending, confirmed, or cancelled.

3. As a clinic receptionist, I want to manage patient appointments, so that I can organize the clinic’s daily schedule and provide better service to patients. (FR3)

Acceptance criteria:

- I can view the list of appointments for a selected date.
- I can confirm, reschedule, or cancel a patient’s appointment.
- I cannot assign two patients to the same doctor at the same time slot.
